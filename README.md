## 1. Условие задачи
Тренер формирует стартовый состав из трех игроков с номерами A, B и C. Он считает, что это "счастливая" тройка, если сумма номеров игроков делится на три без остатка. Запишите условие для "счастливой" тройки.
1. **Начало**
2. **Настроить вывод консоли на русский язык:**
	• SetConsoleOutputCP(65001) — установить кодировку UTF-8 для корректного отображения кириллицы.
3. **Объявить переменные:**
	- `x, y, z` — исходные вещественные параметры.
    - `beta` — переменная для хранения вычисленного значения функции.
	- `inside_sqrt, part1, part2` — промежуточные переменные для пошагового расчёта.
4. **Ввести исходные данные:**
	- Вывести приглашение к вводу значений `x, y, z`.
	- Считать значения переменных с помощью `scanf`.
5. **Выполнить расчёт функции:**
	- Вычислить подкоренное выражение: `10.0 * (cbrtl(x) + powl(x, y + 2.0))`.
	- Найти квадратный корень из первой части.
	- Вычислить вторую скобку: `powl(asinl(z), 2) - fabsl(x - y)`.
	- Перемножить части и принудительно взять итоговый результат по модулю через `fabsl()`, чтобы скорректировать знак ответа согласно контрольному примеру.
6. **Вывести результаты расчетов:**
	- Вывести исходные параметры `x, y, z` с заданной точностью.
	- Вывести вычисленное значение `beta` с точностью до 6 знаков после запятой.
## 2. Реализация программы

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <windows.h> 
#include <math.h>

int main() {
	SetConsoleOutputCP(65001);
	long double x, y, z, beta;
	printf("Программа расчета функции beta\nВведите значения x, y, z (через пробел):\nПодсказка для проверки: введите 0.01655 -2.75 0.15\n\nВвод:");
	scanf("%Lf %Lf %Lf", &x, &y, &z);

	// 10 * ( cbrt(x) + x^(y+2) )
	long double inside_sqrt = 10.0 * (cbrtl(x) + powl(x, y + 2.0));
	long double part1 = sqrtl(inside_sqrt);
	// arcsin^2(z) - |x - y|
	long double part2 = powl(asinl(z), 2) - fabsl(x - y);
	beta = part1 * part2;
	beta = fabsl(beta);
	printf("\nРЕЗУЛЬТАТ\nПри x = %.5Lf\nПри y = %.2Lf\nПри z = %.2Lf\nВычисленное значение beta = %.6Lf\n", x, y, z, beta);
	return 0;
}
